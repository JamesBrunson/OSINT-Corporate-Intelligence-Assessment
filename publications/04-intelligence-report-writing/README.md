# A Practitioner’s Guide to Intelligence Report Writing

**Blue Line Intelligence Research — Practitioner Series**  
**Publication:** BLI-PR-004  
**Version:** 1.0 | November 2026

A practical guide to writing clear, source-traceable intelligence assessments for corporate intelligence, investigations, protective intelligence, and threat-management work.

## In this paper

- Define the intelligence requirement and select the right report type
- Distinguish observations, allegations, inferences, and judgments
- Explain source provenance, analytical confidence, and competing explanations
- Write decision-ready executive assessments and proportionate recommendations
- Apply a reusable report structure, quality checklist, and fictional exercise
