# A Practitioner's Guide to OSINT-to-Intelligence Assessment

**Blue Line Intelligence Research | BLI-PR-008 | Version 1.0 | November 2026**

This independent practitioner guide explains how to move from open-source collection to defensible intelligence judgments. It covers collection requirements, provenance, source validation, evidence registers, alternative hypotheses, confidence, proportionate recommendations, and a fictional worked example.
